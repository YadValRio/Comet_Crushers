# Comet Crushers environment

Adds a base platform, low buildings, side rocks, a small starfield, and cool lighting using Unity primitives, materials, and position/scale changes.

Open SampleScene and enter Play mode. The environment loads automatically after the existing turret setup. Existing game scripts and the saved scene are unchanged. Decorative objects have no active colliders.

The code uses the project's existing URP material shader. Unity compilation and Play-mode testing are still pending.
